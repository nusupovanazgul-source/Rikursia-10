Рекурсия негіздері

Интерактивті оқу материалы және практикалық тапсырмалар

Негізгі ұғымдар

Рекурсия — функцияның өз-өзін шақыру процесі.

1. Тоқтау шарты (Base case) Рекурсияның шексіз жалғаспауы үшін қойылатын шарт. Бұл орындалғанда функция өзін шақыруды тоқтатып, нақты мән қайтарады.
2. Рекурсивті қадам (Recursive step) Функцияның өзін кішірейтілген параметрмен қайта шақыруы.

Рекурсияны түсіну (Матрешка аналогиясы)

Рекурсияны түсінудің ең қарапайым мысалы — Матрешка ойыншығы. Әрбір матрешканың ішінде одан кішірек матрешка болады. Ең соңғы, ашылмайтын ең кішкентай матрешка — бұл Тоқтау шарты (Base case).

Факториалды есептеу мысалы

Математикада $n!$ саны 1-ден $n$-ге дейінгі барлық сандардың көбейтіндісі болып табылады (Мысалы: $3! = 3 \times 2 \times 1 = 6$).

def factorial(n):
    if n == 1:
        return 1  # Тоқтау шарты
    else:
        return n * factorial(n - 1)  # Рекурсивті қадам

Кодты талдау және нәтижесін анықтау

Төменде берілген тапсырмаларды оқып, «Жауапты көрсету» батырмасы арқылы өз жауабыңызды тексеріңіз.

def sum_numbers(n):
    if n == 1:
        return 1
    else:
        return n + sum_numbers(n - 1)

# Сұрақ: sum_numbers(4) не қайтарады?

Жауабы: 10

Түсіндірме: 4 + 3 + 2 + 1 = 10

def power(a, n):
    if n == 0:
        return 1
    else:
        return a * power(a, n - 1)

# Сұрақ: power(2, 3) нәтижесі?

Жауабы: 8

Түсіндірме: 2 * 2 * 2 * 1 = 8

def reverse_str(s):
    if len(s) == 0:
        return s
    else:
        return reverse_str(s[1:]) + s[0]

# Сұрақ: reverse_str("abc") нәтижесі?

Жауабы: "cba"

Рекурсия бойынша өзіндік жұмыс (Exit Ticket)

1. Рекурсивті функцияда «тоқтау шарты» (base case) не үшін қажет?

2. Төмендегі кодта қандай қате бар?

def count_down(n):
    print(n)
    return count_down(n - 1)

3. mystery(3) шақыруының соңғы нәтижесі неге тең?

def mystery(n):
    if n == 1:
        return 1
    else:
        return n + mystery(n - 1)
